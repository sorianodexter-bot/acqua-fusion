# ACQUA FUSION

Website for **ACQUA FUSION Water Refilling Station** — Retail A, Azure North.

## Deploy on Vercel (free)

1. Open https://vercel.com/new
2. Import this GitHub repository
3. Framework: Vite
4. Build command: `npm run build`
5. Install command: `npm install`
6. Deploy

Hobby plan is free. No environment variables required.
